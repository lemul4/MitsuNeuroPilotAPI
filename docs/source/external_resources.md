# Полезные внешние ресурсы

Полезная документация из других репозиториев:

- Шпаргалка по [системам координат CARLA](https://github.com/autonomousvision/carla_garage/blob/leaderboard_2/docs/coordinate_systems.md)
- О [бенчмарке Longest6 v2](https://github.com/autonomousvision/CaRL/tree/main/CARLA#longest6-v2) и [бенчмарке Town13](https://github.com/autonomousvision/carla_garage?tab=readme-ov-file#carla-leaderboard-20-validation-routes)
- Генерация XML-файлов сценариев [случайно](https://github.com/autonomousvision/CaRL/tree/main/CARLA#scenario-generation) и [вручную](https://github.com/autonomousvision/carla_route_generator)

Исследования end-to-end автономного вождения:

- [Why study self-driving?](https://emergeresearch.substack.com/p/why-study-self-driving?triedRedirect=true) Актуальный взгляд с учетом недавних коммерческих запусков сервисов автономного такси.
- [End-to-end Autonomous Driving: Challenges and Frontiers](https://arxiv.org/abs/2306.16927) Подробный вводный обзор области.
- [Common Mistakes in Benchmarking Autonomous Driving](https://github.com/autonomousvision/carla_garage/blob/leaderboard_2/docs/common_mistakes_in_benchmarking_ad.md) Распространенные ошибки, которых следует избегать при оценке систем автономного вождения.
