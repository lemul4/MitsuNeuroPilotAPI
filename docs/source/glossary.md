# Глоссарий

### Route
**Синоним:** Path, spatial path, checkpoints
**Определение:** Пространственный путь с расстоянием 1 м между соседними точками.

### Waypoints
**Синоним:** Trajectory, future positions
**Определение:** Пространственно-временная траектория, описывающая будущие позиции.

### Goal point
**Синоним:** Target point
**Определение:** Точка в ego-системе координат, показывающая, куда нужно ехать.

### Target speed
**Синоним:** Desired speed, reference speed
**Определение:** Желаемая скорость, которой должен достичь автомобиль.

### Command
**Синоним:** Navigation command, high-level command
**Определение:** Высокоуровневая навигационная инструкция (налево, направо, прямо, следовать полосе и т. д.).

### Occupancy map
**Определение:** Растеризованное изображение с отображенными динамическими участниками.

### HD-Map
**Определение:** Растеризованное изображение с отображенной структурой дороги.

### BEV Semantic Segmentation
**Определение:** HD-Map + Occupancy map.

### Persistent Cache
**Синоним:** HDD-Cache
**Определение:** Кэш обучающих данных, который хранится на диске и сохраняется после обучения. Его следует строить только один раз.

### Training Session Cache
**Определение:** В основном используется в контексте SLURM, где каждая SLURM-задача получает собственный быстрый SSD.

### Perturbation
**Синоним:** Sensor perturbation, sensor augmentation.
**Определение:** Сдвиг и поворот сенсорного рига для имитации отклонения от маршрута и обучения модели восстановлению.

### Ensemble
**Синоним:** Averaging.
**Определение:** Ансамблирование нескольких seed для более устойчивого предсказания.

### Buckets
**Связано:** Bucket collection
**Определение:** Бакет = подмножество датасета. Коллекция бакетов = список бакетов. Ее следует строить только один раз.
