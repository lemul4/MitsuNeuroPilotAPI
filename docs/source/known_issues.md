# Известные проблемы

Известные проблемы в pipeline оценки и моделях.

## Обучение на нескольких GPU может немного ухудшить качество

Обучение на 4 GPU иногда дает незначительно более низкое closed-loop качество, чем обучение на одном GPU. Эффект небольшой и не меняет качественных выводов, но стабильно проявляется в некоторых запусках.

## PID-контроллер waypoints в CARLA требует лучшей настройки

Хорошо настроенный контроллер (например, MPC) может существенно улучшить качество. Предварительные эксперименты показали улучшение примерно на ~5–7 DS на Bench2Drive для TFv5, хотя эти числа приблизительны, поскольку tuning контроллера не был основной целью.

## В CARLA 0.9.16 есть проблемы с goal point

В CARLA 0.9.16 сейчас есть проблемы с pipeline goal point, которые ухудшают поведение политики. Мы не рекомендуем оценивать модели на этой версии.

## Версия Torch

Обучение CARLA-агентов лучше всего работает с Torch `2.5.x`. Более новые версии могут приводить к divergence обучения.
