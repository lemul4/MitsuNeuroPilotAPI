# Стабы типов CARLA

Некоторые IDE не поддерживают типизацию CARLA из коробки. Мы используем библиотеку [carla-python-stubs](https://github.com/aasewold/carla-python-stubs),
чтобы генерировать стабы и хранить их для версии 0.9.15 в [3rd_party/typings/carla](https://github.com/kesai-labs/lead/tree/main/3rd_party/typings/carla).
